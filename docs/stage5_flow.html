The six final states (mutually exclusive)

successfulno fault; output validated; EVERY requested measurement ok
recovered_after_failure≥1 named fault, recovery worked, EVERY measurement ok; chain recorded
partially_completedoutput validated; some measurements refused
failedno usable output, or unrecognised/config fault
stopped_budget_limita limit hit; consumed ≤ limit always
rejected_invalid_inputnever reached the simulator
Invariants tested: no state is reachable without its evidence · consumed budget never exceeds a limit · SUCCESSFUL is never emitted when an injected fault was not handled · replay of a stored run matches within rtol 1e-6.
